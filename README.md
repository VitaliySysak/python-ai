Сисак Віталій 4cs-21

Найбільше моделей для класифікації тексту і зображень аналізу сентименту і генерації тексту

Моделі для української є але їх мало більшість або багатомовні або специфічні

Інтерфейс зручний можна швидко знайти потрібну модель і глянути приклади

Використання готових моделей дуже економить час нічого не треба писати з нуля

Плюси швидко просто
мінуси не завжди є під українську або специфічну задачу

В цілому дуже корисно особливо для швидких рішень або навчання
